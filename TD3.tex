\section*{Travail à préparer avant la séance}

Ce TD utilise le module de calcul de distances "OpenRouteService". Une documentation de ce module, dédiée à cet enseignement, est disponible ici : 
\url{https://rtavenar.github.io/doc_openrouteservice/}

Il est donc nécessaire de se créer un compte avant le début du TD.

\begin{itemize}
    \item Créer un compte gratuit sur \url{https://openrouteservice.org/dev/#/signup}
    \item Se rendre sur la page API key en étant connecté avec son compte.
    \item Copier la clé "Basic Key" située en haut de la page : elle sera nécessaire pour chaque requête.
\end{itemize}

\section*{Préambule}
\begin{enumerate}
    \item Télécharger sur Cursus l'archive contenant les données sources du TD3
    \item Décompresser cette archive sur votre disque. 
    Les fichiers doivent se trouver dans PythonOpenData/TD3.
    \item Lancer l'éditeur Visual Studio Code.
    \item Dans Visual Studio Code, ouvrir le dossier PythonOpenData/TD3. 
\end{enumerate}


\section{Préparation de la clé d'API}
\begin{enumerate}
    \item Dans le fichier credentials.json, insérer votre clé d'API préalablement créée.
    \item Dans le fichier td3.py, la fonction fournie \verb+acces_cle_api+ permet de lire la clé API dans le fichier credentials.json. 
    Utiliser cette fonction pour afficher votre clé d'API.
\end{enumerate}
        
\section{Obtenir des coordonnées GPS}
\begin{enumerate}
    \item Etudier la documentation de l'API de géocodage.
    \item Par similitude, obtenir les coordonnées GPS de "Rennes Beaulieu".
    \item A partir de cet exemple, écrire une fonction \verb+adresse_vers_gps+ qui prend en entrée une clé d'api et une adresse textuelle, et renvoie les coordonnées gps, sous forme d'un tuple (longitude, latitude).
    \item Tester cette fonction pour calculer les coordonnées GPS de "Rennes Villejean".
\end{enumerate}


\section{Calculer la distance d'un trajet}

\begin{enumerate}
    \item Etudier la documentation de l'API d'itinéraires. 
    \item Écrire une fonction \verb+distance_trajet+ qui prend en entrée une clé d'api, les coordonnées gps d'un premier lieu, et les coordonnées gps d'un second lieu. Cette fonction doit renvoyer la distance en kilomètre, en voiture, entre les deux lieux. Les coordonnées sont données sous la forme d'un tuple (longitude, latitude).
    
    \emph{Indice :} On pourra s'inspirer largement de la fonction \verb+adresse_vers_gps+. Il faudra changer principalement 3 éléments : l'url de l'api appelée, les paramètres de la requête, la lecture du résultat.
    
    \item Calculer la distance en voiture de Villejean à Beaulieu, puis de Beaulieu à Villejean.
    \item Utiliser toutes les fonctions précédemment écrites pour calculer la distance de Rennes à Brest.
\end{enumerate}

\section{Calculer la durée d'un trajet}

\begin{enumerate}
    \item  Écrire une fonction \verb+duree_trajet+ qui prend en entrée une clé d'api, les coordonnées gps d'un premier lieu, et les coordonnées gps d'un second lieu. Cette fonction doit renvoyer la duree en secondes, en voiture, entre les deux lieux. Les coordonnées sont données sous la forme d'un tuple (longitude, latitude).
    \item Tester cette fonction pour calculer la durée en voiture de Villejean à Beaulieu.
    \item Modifier la fonction \verb+duree_trajet+ pour qu'elle prenne un attribut facultatif \verb+mode+, correspondant au mode de transport. Cet attribut vaut \verb+driving-car+ par défaut.
    
    \item Afficher la duree pour aller de Villejean à Beaulieu en vélo puis à pieds.
    
\end{enumerate}

\section{Voyage à étapes}
On définit un voyage comme une liste de lieux (chaines de caractère). Chaque lieu de la liste est une étape du voyage.

Pour toutes les fonctions demandées, penser à chaque fois à utiliser d'autres fonctions existantes !

\begin{enumerate}
    \item Une variable \verb+voyage1+ est définie dans le fichier source. Définir un second voyage de votre choix.
    \item Définir une fonction \verb+distances_etapes+ qui prend en entrée un voyage, un client GraphHopper, et renvoie la liste des distances de chaque étape. Tester sur les deux voyages.
    \item Définir une fonction \verb+distance_totale+ qui prend en entrée un voyage et un client GraphHopper, et renvoie la distance totale du trajet en passant par chacune des étapes.
\end{enumerate}
